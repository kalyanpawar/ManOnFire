# Java Practice Programs

This repository contains basic Java programs for practice.

**🟢 BASIC LEVEL (Fundamentals & Logic)**

**Print numbers from 1 to N without using loops.
Check whether a number is prime.
Reverse a given integer.
Find the largest of three numbers without using built-in functions.
Count the number of digits in a number.
Check if a string is a palindrome.
Find the factorial of a number using recursion.
Print the Fibonacci series up to N terms.
Count vowels and consonants in a string.
Swap two numbers without using a temporary variable.
Find the sum of digits of a number.
Check if a year is a leap year.
Convert Celsius to Fahrenheit and vice versa.
Find the second largest element in an array.
Check if two strings are anagrams.**

**🟡 MEDIUM LEVEL (Data Structures & Algorithms)**

**Arrays & Strings**
**Rotate an array to the right by K positions.
Find all pairs in an array whose sum equals a given value.
Remove duplicate characters from a string without using extra space.**
**Find the longest word in a sentence.**
**Merge two sorted arrays without using extra space.**
Find the missing number in an array containing numbers from 1 to N.
Find the longest common prefix among a list of strings.
Implement string compression (e.g., aabcc → a2b1c2).
Check if one string is a rotation of another.
Find the first non-repeating character in a string.

**Linked List / Stack / Queue**
Reverse a linked list.
Detect a cycle in a linked list.
Implement a stack using arrays.
Implement a queue using two stacks.
Check for balanced parentheses in an expression.
Find the middle element of a linked list in one traversal.

**Searching & Sorting**
Implement binary search recursively.
Sort an array using merge sort.
Find the Kth largest element in an array.
Find the element that appears more than N/2 times.

🔴 **ADVANCED LEVEL (Problem Solving & System Thinking)**

**Recursion & Backtracking**
Solve the N-Queens problem.
Generate all permutations of a string.
Generate all valid parentheses combinations for N pairs.
Solve a Sudoku puzzle.
Find all subsets of a given set.

**Dynamic Programming**
Solve the 0/1 Knapsack problem.
Find the longest increasing subsequence.
Find the longest common subsequence of two strings.
Solve the coin change problem.
Find the minimum number of jumps to reach the end of an array.

**Graphs & Trees**
Implement Depth First Search (DFS) and Breadth First Search (BFS).
Detect a cycle in a directed graph.
Find the shortest path in a weighted graph.
Check if a binary tree is a binary search tree.
Find the lowest common ancestor in a binary tree.
Serialize and deserialize a binary tree.
Find the diameter of a binary tree.
Concurrency / Design / Real-World Problems
Design an LRU cache.
Implement a thread-safe singleton.
Design a URL shortener.
Implement a rate limiter.
Design a parking lot system.
Design a file system structure.
Implement a producer-consumer problem.
